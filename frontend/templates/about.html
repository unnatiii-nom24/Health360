Project notes

What Health360 does
and what it does not.

A student data-analytics project focused on preparing a healthcare dataset, building clear visual comparisons, and making the results easier to explore through a small Flask web application.

01 · Data preparation

The CSV is loaded with Pandas. Age bands and BMI categories are derived for charting, and basic checks summarize missing values, duplicate rows and field variation.

02 · Visualization

Plotly charts show age-group counts, exercise distribution, BMI categories, average blood-pressure values, disease flags, lifestyle flags and group comparisons.

03 · Web application

Flask serves the pages. Query-string filters let users choose age group, gender, BMI category and exercise level; the charts and KPI summaries update for the selected records.

Run it on your computer

See the README file included with the project ZIP for step-by-step setup.

  1. Install Python 3.10 or later.
  2. Install the dependencies with pip install -r requirements.txt.
  3. Run python app.py in the project folder.
  4. Open http://127.0.0.1:5000 in your browser.

Internet access is required for the Plotly chart library loaded from its CDN.
