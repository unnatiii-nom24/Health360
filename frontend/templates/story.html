A guided look at the dataset

From patient profile
to patterns worth exploring.

This story walks through the supplied 5,000-record dataset in a sequence of small questions. The findings are descriptive: they show what appears in this file, not what causes a condition or what will happen to an individual.

SCENE 01

Start with the dataset

The analysis includes {{ "{:,}".format(patient_count) }} records covering age, gender, BMI, exercise, smoking and alcohol flags, clinical measurements, symptoms, disease labels and a health-risk score. Checking the size and field types first helps keep later comparisons grounded in what the file actually contains.

SCENE 02

Look at the recorded clinical measures

The average recorded blood-pressure value across the dataset is {{ avg_bp }}, and the average BMI is {{ avg_bmi }}. These are descriptive summaries only. The source file does not provide enough clinical context to label the blood-pressure average as a diagnosis or to interpret individual measurements.

Average blood-pressure value by age group

SCENE 03

Compare the disease flags

In the full dataset, {{ heart_pct }}% of records have the heart-disease field coded as 1, {{ diabetes_pct }}% have the diabetes field coded as 1, and {{ stroke_pct }}% have the stroke field coded as 1. These percentages describe the dataset's labels and should not be assumed to represent the prevalence in a wider population unless the data source and sampling method support that conclusion.

Positive disease flags in the file

SCENE 04

Explore lifestyle and group differences

Age group, BMI category and exercise level offer practical ways to segment the records. The dashboard allows viewers to compare these segments and check whether a pattern is consistent across more than one chart. An observed association is a reason to investigate further, not proof of cause and effect.

Heart-disease flag by BMI category and exercise level

SCENE 05

One data issue needs attention

The health_risk_score field has {{ risk_unique }} unique value in the supplied CSV: it is 100 for every record. Since it does not separate records, it cannot currently rank patients or act as an informative risk indicator. The score's source or calculation should be checked before any further use.

Health360 is an exploratory analytics project. It is not a diagnostic tool and should not be used to make treatment decisions.
